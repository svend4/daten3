# TravelHub — туристический проект

Материалы сайта и веб-приложения для поиска и бронирования путешествий с партнёрскими программами. Репозиторий содержит старые PHP-страницы, несколько HTML/React-вариантов TravelHub и документы по интеграции, безопасности, SEO и развёртыванию.

Здесь сохранены разные версии и архивы, поэтому для ориентира начните с `README_v1.1.txt` и `FINAL_REPORT.md`.
